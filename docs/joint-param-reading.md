# 关节参数读取方法（换关节 / 标定时用）

通过 EtherCAT SDO 读取驱动 OD 对象，获取关节本体参数。用于标定单位换算、核对不同关节的配置。

## 探针工具

源码：`tools/read_joint_params.cpp`（独立于 GUI，需 SDK 编译）。

```bash
# x86 编译（SDK 路径按实际改）
g++ -o /tmp/odtorque tools/read_joint_params.cpp \
  -I<SDK>/include -L<SDK>/lib -leu_ethercat -lsoem -lcyhcs_log

# 运行（网卡名用 `ip link` 看）
sudo LD_LIBRARY_PATH=<SDK>/lib /tmp/odtorque <网卡名>   # 例: enx00e04c3a41c0
```

## 关键 OD 对象（CiA402 + 厂商）

| 索引 | 含义 | 读取方式 | 本关节(PHU-20H-90-F-B)实测 |
|---|---|---|---|
| 0x6080 | 最大电机转速 (rpm) | SDO uint32 | 3500 |
| 0x6076 | 额定扭矩 | SDO uint32 | 850 |
| 0x6075 | 额定电流 | SDO uint32 | 9333 |
| 0x6072 | 最大扭矩 | SDO uint32 | 3030 |
| 0x60E0/0x60E1 | 正/负向扭矩限制 | SDO uint32 | 3030 / 3030 |
| 0x608F:1/2 | 编码器分辨率 分子/分母 | SDO uint32 | 524288 / 1 |
| 0x6091 | 减速比 | SDO uint32 | **不可靠**(1/1，实物 101) |
| 0x6081/0x6083/0x6084 | 轮廓速度/加速度/减速度 | SDO uint32 | — |
| 0x6098 | 归航方法 | SDO uint8 | 35 |
| 0x6099 | 归航速度 | SDO uint32 | — |
| 0x60C2 | 最大跟随误差 | SDO uint32 | — |

## 注意事项

1. **SDO 超时**：探针用 2000ms。SDK 例程甚至用 20000ms。太短（如 20ms）会读失败。
2. **遥测读取别用 SDO**：位置/力矩/状态字这些高频量用 `eth_getActualPosition/Torque/StatusWord/...`（PDO 路径）。实测本驱动这些对象走 SDO 短超时读会失败。
3. **单位换算关键——额定扭矩**：
   - `命令: N·m → 千分比 = N·m × 1000 / ratedNm`
   - `读回: 千分比 → N·m = 千分比 × ratedNm / 1000`
   - ratedNm 设错会**命令超发/少发 + 显示少读/多读**。定额定用探针读 0x6076 和 0x6072，比值对照设计文档的「启停/额定」或「瞬时/额定」。
4. **0x6091(减速比) 与 0x6076(额定) 的 OD 值不可靠**：减速比一律在连接对话框手动填（本关节 101），额定用设计文档型号值（本关节 90mm = 50 N·m）。
5. **真实值核对**：0x6076=850、0x6072=3030，比值 3.56 ≈ 90mm 的瞬时/额定 = 182/50 = 3.64，故额定取 50。
6. **最大转速 0x6080=3500 rpm**：力矩模式空载时电机 <1s 冲到 3500 rpm，触发驱动速度保护自动停机（禁止合闸）。想持续测力矩必须加载（磁粉制动器）。
