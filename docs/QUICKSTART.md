# 模拟量输出模块 + 张力控制器 快速上手 (Quickstart)

LubanCat 板通过 RS485 控制 4 路 0~10V 模拟量输出模块,再接到张力控制器的电压设定输入。
PC 作为上位机,可通过 SSH 或 socat 网关访问板上的 RS485。

## 1. 硬件连接

### RS485 总线 (板 ↔ 模块)

| 板端 | 模块 |
|------|------|
| ttyS3 485A | A(+) |
| ttyS3 485B | B(-) |

- 模块接在 **ttyS3** 上(发送口)。
- A/B 接反会完全无应答,对调即可。
- 485 总线一般要求两端终端电阻(120Ω),短线测试可暂不加。

### 模块 → 张力控制器 (电压设定输入)

```
AO 模块 +  ──────▶  张力控制器 adj
AO 模块 -  ──────▶  张力控制器 gnd
```

接之前查张力控制器手册,确认两件事:
1. **adj 是电压输入(0~10V)还是电流输入(4~20mA)**。电压直接接;电流需要换模块或跳线切到电压挡。
2. **adj 量程是 0~10V 还是 0~5V**。0~5V 时模块数值只能用到 0~5000,不要超过。

## 2. 模块通信参数

| 项目 | 值 |
|------|-----|
| 协议 | Modbus RTU |
| 从机地址 | 1 |
| 波特率 | 9600, 8N1 |
| 数值单位 | mV, 寄存器值 = 电压 × 1000 |
| 量程 | 0~10000 (0.000V ~ 10.000V) |
| 寄存器 | CH1=0x0050  CH2=0x0051  CH3=0x0052  CH4=0x0053 |

功能码:0x06 写单寄存器 / 0x10 批量写 / 0x03 读保持寄存器。

> 注意:早期手册示例报文 `01 06 00 50 0C E8 89 65` 数值与 CRC 不自洽,勿照抄。
> 用下面程序 `-n` dry-run 生成的帧为准。

## 3. 软件与编译

文件位于 `arm/` 目录:

- `modbus_ao.c`       主站(核心工具)
- `modbus_slave_sim.c` 假模块模拟器(模块到货前回环测试用)
- `rs485_test.c`      原始字节回环测试

拷贝到板上并在板上编译:

```bash
scp modbus_ao.c cat@<板子IP>:~/rs485/
ssh cat@<板子IP>
cd ~/rs485
gcc -o modbus_ao modbus_ao.c
gcc -o modbus_slave_sim modbus_slave_sim.c   # 可选
gcc -o rs485_test rs485_test.c               # 可选
```

## 4. 快速测试

```bash
# 四路同时输出 1.0 / 2.0 / 3.0 / 4.0 V
./modbus_ao --all 1000,2000,3000,4000

# 单路写 CH1 = 3.212V
./modbus_ao -c 1 -v 3212

# 回读三/四路,确认值真的写进去了
./modbus_ao -r

# 只打印报文不发送,核对 CRC
./modbus_ao -n -c 1 -v 3212

# 换一组电压
./modbus_ao --all 2000,3500,5000,8000
```

命令参数:

| 参数 | 含义 | 默认 |
|------|------|------|
| `-c <1..4>` | 通道 | - |
| `-v <mv>` | 数值 0~10000 | - |
| `--all <mv,mv,mv,mv>` | 批量写四路 | - |
| `-r` | 读回 | - |
| `-d <dev>` | 串口设备 | /dev/ttyS3 |
| `-b <baud>` | 波特率 | 9600 |
| `-a <addr>` | 从机地址 | 1 |
| `-n` | dry-run 只打印帧 | 关 |
